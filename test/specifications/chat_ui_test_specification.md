## テスト優先度の定義

| 優先度 | 定義 |
|--------|------|
| **高** | コア機能に関わるテスト。失敗した場合、製品の主要な機能が動作しない |
| **中** | 重要な機能に関わるテスト。失敗した場合、一部の機能が制限されるが、主要な機能は動作する |
| **低** | エッジケースやニッチな機能に関するテスト。失敗した場合、特定の条件下でのみ問題が発生する |

## テスト実行ガイドライン

### 事前準備
1. テスト環境が正しく設定されていることを確認する
2. ActionCable/WebSocket サーバーが実行中であることを確認する
3. テストデータベースが適切に初期化されていることを確認する

### システムテストの実行
```bash
# すべてのシステムテストを実行
rails test:system

# 特定のテストファイルを実行
rails test:system test/system/chat_ui_system_test.rb

# 特定のテストを実行
rails test:system TESTOPTS="--name=/ST-001/"
```

### JavaScript/Stimulus テストの実行
```bash
# Jest を使用する場合
npm test

# 特定のテストファイルを実行
npm test message_controller.test.js
```

### 統合テストの実行
```bash
# すべての統合テストを実行
rails test:integration

# 特定のテストファイルを実行
rails test test/integration/chat_flow_integration_test.rb
```
